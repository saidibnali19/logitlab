# apps/web

The LogitLab web app: Next.js 16, React 19, TypeScript and Tailwind 4. It displays the JSON results that the Python engine in `packages/engine` generates.

What LogitLab is, how it decides, the statistics behind it and how to run it locally are in the [root README](../../README.md).

From the repository root, `npm run dev` starts this app at http://localhost:3000.
